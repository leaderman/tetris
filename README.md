# 俄罗斯方块 (Tetris)

一个纯前端、零依赖的俄罗斯方块游戏，全部实现于单个 `game.html` 文件中（HTML + CSS + 原生 JavaScript + Canvas）。

## 运行

直接用浏览器打开即可，无需安装任何依赖、无需构建：

```bash
open game.html        # macOS
# 或者把 game.html 拖进浏览器
```

## 操作

| 按键 | 功能 |
|------|------|
| `A` / `D` | 左右移动（长按连续移动） |
| `S` | 软降（长按持续下落） |
| `空格` | 硬降（直接落到底） |
| `W` | 顺时针旋转 |
| `Z` | 逆时针旋转 |
| `C` | 暂存当前方块（Hold） |
| `N` | 换块：丢弃当前块，取队列下一个，队尾从随机袋补一个 |
| `1` ~ `7` | 指定方块：丢弃当前块，换成对应形状（旋转随机） |
| `R` | 撤销：回退到上一回合（游戏结束界面也可用，相当于复活） |
| `P` | 暂停 / 继续 |
| `Enter` | 游戏结束后重新开始 |

方向键同样可用（← → 移动、↓ 软降、↑ 旋转）。

顶部的横向图例展示了数字 `1`~`7` 分别对应的 7 种方块形状。

## 功能特性

- **标准 7-bag 随机**：每 7 个方块为一袋，保证 7 种形状均匀出现
- **锁定延迟（Lock Delay）**：方块落地后有 500ms 缓冲可微调，移动/旋转刷新计时（上限 15 次）
- **DAS / ARR 连续移动**：长按左右先延迟再连发，手感顺滑
- **幽灵落点提示**：显示当前方块的最终落点
- **暂存（Hold）** 与 **NEXT 预览**（显示后续 3 个方块）
- **撤销**：可连续回退（最多 100 步），支持游戏结束后复活
- **换块 / 指定方块**：随时更换正在下落的方块
- **计分系统**：消行得分、连击（Combo）加成、随等级递增
- **等级与速度**：每消除 10 行升一级，下落随之加快
- **视觉效果**：伪 3D 像素方块、消行闪烁、升级闪光、扫描线 / 暗角等复古风格
- **自适应布局**：根据视口高度自动缩放棋盘、面板与字号

## 计分规则

| 消除行数 | 基础分（× 当前等级） |
|----------|----------------------|
| 1 行 | 100 |
| 2 行 | 300 |
| 3 行 | 500 |
| 4 行（Tetris） | 800 |

- 连续消行触发 **连击（Combo）**，额外加 `50 × 连击数 × 等级`
- 软降每格 +1 分，硬降每格 +2 分

## 技术说明

- 单文件实现，无外部依赖
- 渲染：HTML5 Canvas，逐帧 `requestAnimationFrame` 驱动
- 旋转使用简化的踢墙（wall kick）尝试
- 主要可调参数（位于 `<script>` 开头）：`LOCK_DELAY`、`DAS`、`ARR`、`SOFT_ARR`、`COLS`、`ROWS`、`CELL`
